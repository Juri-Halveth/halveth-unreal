# HALVETH Portal Garden 0.2.0

**Краткий путеводитель по проекту · EN / RU**

Независимый нативный прототип мира на C++ для Unreal Engine 5.8. Описанный игровой цикл соединяет четыре мира: исследование, авторскую библиотеку, рецепты, ремесло, зачарование, строительство и локальные сохранения.

Это отдельный проект Unreal. Он не преобразует установленный Morrowind, не импортирует сохранения Morrowind и не изменяет Genesis/OpenMW. Проверенный состав сборки и его ограничения описаны в отчёте нативной проверки; ресурсы движка и сторонний контент сохраняют свои условия использования.

Этот путеводитель составлен и отредактирован вручную по проверенному источнику. Исходная техническая документация остаётся справочным материалом для команд, требований сборки, точных версий и подробных проверок.
