# Original Scarlet Heart icon

`assets/icon.svg` and `Build/Windows/Application.ico` reuse the original HALVETH Realms Scarlet Heart artwork. The SVG was authored as vector geometry; the ICO contains seven rendered sizes: 16, 24, 32, 48, 64, 128 and 256 pixels.

Source: [HALVETH Realms, commit e2bd4c64fa75d42a7e5119b97b78b0a9681e1ba1](https://github.com/Juri-Halveth/halveth-realms/tree/e2bd4c64fa75d42a7e5119b97b78b0a9681e1ba1/assets).

The retained MIT notice is in `assets/ICON-LICENSE.txt`. The artwork does not contain a Marvel logo, character image, or Bethesda asset. Unreal uses `Build/Windows/Application.ico` when building the Windows application resource.
