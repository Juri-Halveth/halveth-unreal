## Release integration

- Include this document with the packaged Unreal build and show the two product-credit paragraphs in its credits view.
- Present the runtime terms with the product's end-user terms. Retain the packaged engine notices. The runtime terms concern Epic's technology; they do not remove the permissions granted for original MIT-licensed HALVETH code or explicitly designated CC0 assets.
- Keep engine source, the editor and developer tooling outside the freely public project source export. A runtime package and an engine-source distribution have different distribution conditions.
- The project name above matches the current `ProjectName` value, **HALVETH Portal Garden**. Update the credit name when the product title changes, and the copyright year for a later release.
- These engine notices apply only to an Unreal edition. A separate OpenMW/Morrowind adapter does not acquire an Unreal dependency merely because this reference file is available alongside shared licensing materials.
