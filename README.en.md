# HALVETH Portal Garden 0.2.0

**Concise project guide · EN / RU**

An independent native C++ world prototype built for Unreal Engine 5.8. The documented play loop connects four realms with exploration, an original living library, recipes, crafting, enchantment, construction and local persistence.

This is a separate Unreal project. It does not convert a Morrowind installation, import a Morrowind save or modify Genesis/OpenMW. Consult the native validation record for the tested build and its limits; engine resources and third-party content retain their own terms.

This manually edited guide summarizes the audited source. The original technical documentation remains the reference for commands, build requirements, exact versions and detailed evidence.
